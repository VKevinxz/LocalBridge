# Participación en LocalBridge MCP

LocalBridge se publica como código visible con `license: UNLICENSED`. No es un proyecto
open source y actualmente **no acepta contribuciones externas de código ni pull requests**.
No copies, modifiques o redistribuyas el código para preparar una contribución sin permiso
previo del propietario.

## Qué sí puedes aportar

- reportar un fallo reproducible mediante una
  [incidencia](https://github.com/VKevinxz/LocalBridge/issues/new/choose);
- proponer mejoras describiendo el problema y el resultado esperado en el mismo formulario;
- comunicar de forma privada una vulnerabilidad;
- compartir resultados de instalación en Windows sin datos personales.

Antes de publicar un reporte, elimina claves, tokens, rutas personales, contenido de
proyectos, bases de auditoría y configuraciones locales. Incluye versión, edición de
Windows, pasos mínimos y resultado esperado/observado.

## Seguridad

No publiques vulnerabilidades en issues. Sigue [SECURITY.md](SECURITY.md). Las
interacciones públicas se rigen por [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), y los derechos
sobre el código se explican en [COPYRIGHT.md](COPYRIGHT.md).

Si el propietario abre contribuciones en el futuro, publicará antes las condiciones y el
proceso correspondientes.
