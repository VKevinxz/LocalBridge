# LocalBridge MCP v1.6.1

Corrección de fiabilidad para investigación y réplica web basada en una ejecución real.

## Cambios

- captura temporal 1920×1080 con PNG comprimido y preflight antes del scroll;
- causa segura para efectos inciertos y códigos visibles en la auditoría local;
- cuota web independiente: 100 MiB por asset y 1 GiB acumulado por sesión de forma
  predeterminada, ampliable localmente hasta 1 GiB/10 GiB;
- descargas por chunks hacia staging, hash incremental, reserva de disco y publicación
  atómica;
- errores estables y recuperación verificada al navegar o recargar;
- recomendaciones de loopback, tools estructuradas, relectura de parches, truncado y
  esperas realistas.

Mantiene 89 tools, el flujo de desarrollo de v1.6.0 y los límites de autoridad. El broker
privado usa revisión 17.
