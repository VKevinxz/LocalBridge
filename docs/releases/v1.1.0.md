# LocalBridge MCP v1.1.0

Primera preview pública del flujo project-first para Windows x64.

## Novedades

- onboarding de seis pasos centrado en proyectos;
- comprobación automática del runtime autocontenido;
- selección única de carpeta y detección read-only de repo, monorepo o multirepo;
- acceso Guiado por defecto y Control total avanzado con consentimiento local;
- migración compatible desde configuraciones `v1.0.3`;
- finalización transaccional, reanudación e idempotencia.

## Compatibilidad

- protocolo MCP `2026-07-28` sin cambios;
- no requiere reinstalar un conector ya registrado por cambios de catálogo;
- proyectos, aplicaciones, claves y permisos existentes se conservan;
- `Agente en proyecto` permanece no disponible sin sandbox demostrado.

## Instalación

Descarga el instalador y `SHA256SUMS.txt` adjuntos a esta release. Verifica SHA-256 y firma
Authenticode con timestamp antes de instalar. El paquete incluye todos los runtimes
necesarios; no requiere Node.js.

No desactives protecciones de Windows para ejecutar un candidato no firmado. Consulta
[Instalación segura en Windows](../WINDOWS_INSTALLATION.md).

Consulta la [guía de instalación](../GETTING_STARTED.md) y
[operaciones](../OPERATIONS.md).

## Límites de la preview

- soporte inicial: Windows x64;
- no incluye actualización automática;
- Control total tiene la autoridad de la cuenta Windows y debe habilitarse conscientemente;
- usa cuentas y datos de prueba durante intervención humana en páginas locales.

Los problemas conocidos y pasos de recuperación se mantienen en
[TROUBLESHOOTING.md](../TROUBLESHOOTING.md).
