# LocalBridge MCP `v1.4.0`

`v1.4.0` amplía LocalBridge desde el trabajo de programación hacia tareas cotidianas en
ChatGPT, manteniendo intacto el ámbito de desarrollo.

## Navegador de Internet aislado

- 21 tools `web.*` para perfiles, sesiones, pestañas, navegación, extracción, interacción,
  espera, descarga y transferencia humana;
- perfiles públicos y perfiles limitados a sitios elegidos localmente, deshabilitados por
  defecto;
- Chromium efímero con proxy HTTPS mediado, DNS/IP público comprobado, red privada y
  metadata bloqueadas, permisos cerrados, QUIC y WebRTC no mediado deshabilitados;
- referencias separadas por pestaña y generación, un escritor por pestaña e idempotencia
  que no repite efectos inciertos.

## Carpetas, documentos y resultados

- las tools de workspace funcionan también con carpetas sin Git ni setup de desarrollo;
- `document.read` extrae texto y páginas de PDFs mediante un worker limitado sin acceso a
  rutas o red;
- `web.download` guarda únicamente recursos observados en PDF, JSON, CSV, TXT o Markdown,
  dentro de un workspace escribible, sin sobrescribir ni ejecutar;
- informes se crean y se verifican con las tools de archivo existentes.

## Privacidad y coexistencia

- el login requiere **Tomar control** en la aplicación; el agente queda excluido desde la
  solicitud hasta la devolución;
- perfiles, sesiones y presupuestos web son independientes de terminales, procesos,
  `browser.*`, workspaces y confianza;
- actualizar no concede Internet ni cambia proyectos, permisos o el modo de aprobación Git;
- el control de aplicaciones nativas de Windows, teclado/ratón global, subidas, OCR y
  DOCX/XLSX quedan fuera de esta versión.

## Compatibilidad

El protocolo MCP público continúa en `2026-07-28`. El broker privado sube a revisión 13 y
falla cerrado si la aplicación y el servidor no coinciden. El catálogo pasa de 57 a 79
tools. La última preview remota continúa en `v1.2.1.2`; este candidato no fue publicado.
