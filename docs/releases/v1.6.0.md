# LocalBridge MCP v1.6.0

Esta versión añade evidencia temporal para analizar y comparar animaciones durante scroll,
y corrige el recorte silencioso del visor cuando ChatGPT renderiza a 1920×1080 en una
pantalla menor.

## Funciones principales

- cinco tools nuevas: inspección y captura para Internet/localhost, más comparación
  temporal;
- bundles `.lbmotion` atómicos con frames, manifiesto, hashes y hoja de contacto;
- captura `stepped` y `screencast` con límites, backpressure, progreso y cancelación;
- visor **Encajar | 1:1** con pan local y métricas separadas de Render, visible y escala;
- recuperación de staging después de un cierre abrupto;
- 89 tools y broker privado revisión 16.

El instalador incluye todos los cambios. Tras actualizar, reinicia LocalBridge y reconecta
el conector en ChatGPT para refrescar el catálogo. Consulta
[la guía de prueba](../V1.6.0_TEST_GUIDE.md) y
[la auditoría de cierre](../V1.6.0_COMPLETION_AUDIT.md).

## Límites conocidos

La versión recorre únicamente el scroll vertical del documento y compara por el mismo
vector de progreso. Canvas/WebGL se observa visualmente, pero no siempre puede describirse
como animación semántica. Sitios dinámicos pueden necesitar varias corridas. No se graba
audio, MP4, el escritorio ni el navegador personal.
