# LocalBridge MCP v1.8.0

Fecha del candidato: 12 de septiembre de 2026.

## Qué cambia

- ChatGPT puede inspeccionar estilos calculados y variables CSS sin modificar el proyecto.
- Puede recorrer menús con varias teclas conservando el foco y detenerse antes de escribir
  en un campo sensible.
- Puede ejecutar un click, hover o tecla y capturar el estado resultante en una sola
  operación recuperable, útil para Toast, tooltip, diálogo y transiciones breves.
- Las esperas pueden observar estabilidad local; las recargas distinguen modo normal y sin
  caché; consola y eventos conservan datos estructurados acotados y navegación actual.
- Motion incorpora evidencia de calidad por frame y comparación opcional por scroll real.
  Una diferencia de posición o entorno produce advertencia en vez de una conclusión falsa.
- Las diferencias PNG pueden localizar regiones geométricas paginadas sin cambiar el ratio
  global.
- La lectura de terminal puede esperar salida nueva y explica qué límite se agotó.

## Trabajo simultáneo

Las nuevas tools `task.runMany`, `task.list`, `task.statusMany`, `task.waitMany` y
`task.cancelMany` agrupan análisis largos y validaciones finitas. El lote continúa con
Desktop abierto aunque el usuario cambie de conversación. Los resultados parciales se
pueden consultar sin relanzar el trabajo.

El coordinador reutiliza `AnalysisJobSupervisor`, el runner de validación y sus permisos.
No es un segundo agente ni ejecuta comandos arbitrarios. Dos fuentes o workspaces
independientes pueden avanzar juntos; operaciones sobre el mismo recurso esperan de forma
visible. Validaciones del mismo workspace conservan su mutex y motion sigue siendo global.

La admisión completa ocurre antes del primer efecto. Las rutas permanecen relativas, las
referencias web siguen siendo opacas y cada hijo vuelve a comprobar autoridad al empezar y
al entregar. Un `operationId` repetido devuelve el mismo recibo; otra intención falla. El
journal no guarda parámetros, texto, imágenes, stdout, stderr ni URLs sensibles.

## Compatibilidad

Las 100 tools de 1.7.0 mantienen sus nombres y rutas. Se agregan trece para un total de
113. El broker privado sube de revisión 19 a 22, por lo que Desktop y el servidor del mismo
paquete deben actualizarse juntos. Los bundles motion antiguos siguen siendo legibles y la
ausencia de metadata de calidad se informa como `unknown`.

Actualizar no amplía permisos, cuotas ni confianza, no reinicia el wizard y no añade
confirmaciones a acciones ya autorizadas. `task.*` queda aislado si su journal falla; Git,
terminal, navegador y tools individuales continúan disponibles.

## Límites efectivos

- 24 hijos por lote; 32 lotes y 256 hijos no terminales.
- 20 hijos por página, 32 esperas de hasta 20 segundos.
- 2 MiB por resultado de validación y 16 MiB agregados en memoria.
- Hasta 512 lotes durante un máximo de siete días.
- Captura motion, render PDF y comparaciones conservan sus semáforos anteriores.

Estos límites administran trabajo y metadata. No reducen el modo avanzado **Sin límite
fijo** para fuentes grandes ni cambian las cuotas web configuradas.

## Evidencia

El candidato incluye una medición reproducible de concurrencia y una auditoría interna de
cierre con trazabilidad de requisito, código, pruebas y paquete. Pasaron 1160 pruebas
funcionales, 339 de seguridad, los cuatro verificadores Electron, el smoke del escritorio
y las tres pruebas del servidor MCP empaquetado.

La prueba real en ChatGPT continúa siendo necesaria para evaluar selección autónoma de
tools y calidad del resultado, pero no sustituye las verificaciones automatizadas y físicas
del candidato.
