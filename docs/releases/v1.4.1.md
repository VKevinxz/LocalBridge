# LocalBridge MCP `v1.4.1`

`v1.4.1` permite ver en tiempo real el navegador de investigación que usa ChatGPT, sin
convertir esa ventana en una superficie de control ni cambiar la autoridad existente.

## Vista web en vivo

- **Ver y seguir** muestra la última pestaña usada por una acción de ChatGPT;
- cualquier pestaña se puede fijar y la pantalla se elige desde LocalBridge;
- se muestra la página real: abrir, mover u ocultar conserva `WebContents`, historial,
  viewport, sesión, proxy y referencias;
- cerrar la ventana desde Windows equivale a ocultarla y la investigación continúa;
- solo hay una vista pasiva visible entre investigación y navegador de desarrollo, pero
  ambos trabajos siguen activos al alternar.

## Privacidad y seguridad

- la banda de LocalBridge está separada del contenido remoto, sin preload, Node, red ni
  permisos;
- la ventana pasiva no acepta foco, ratón o teclado;
- observar requiere únicamente `read` ya habilitado en el perfil y no añade permisos;
- una solicitud de control humano retira toda vista pasiva antes del intervalo privado;
- al devolver el control, la vista web queda oculta hasta otra acción local;
- aperturas tardías se invalidan tras ocultar, revocar o cambiar autoridad.

## Compatibilidad

El catálogo permanece en 79 tools, el protocolo MCP en `2026-07-28` y el broker privado
en revisión 13. No hace falta reinstalar el complemento si continúa apuntando al mismo
túnel; reinicia LocalBridge, reconecta y abre una conversación nueva para refrescar estado.

La automatización de aplicaciones nativas de Windows, el control global de escritorio,
subidas y grabación de sesiones continúan fuera de esta versión. El candidato local no se
publica automáticamente y el instalador permanece sin firma.
