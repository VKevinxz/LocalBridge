# LocalBridge MCP `v1.2.0`

`v1.2.0` permite comprobar el diseño responsive de una aplicación web local desde el
navegador controlado. Incluye además las correcciones de `v1.1.1` y `v1.1.2`.

## Pruebas responsive

Hasta ahora, cada sesión del navegador se abría con un tamaño fijo y no había forma de
cambiarlo, así que verificar cómo se ve una vista en móvil, tableta o pantalla ancha obligaba
a abrir el navegador a mano.

Ahora el asistente puede pedir un tamaño de vista concreto y recorrer los puntos de ruptura
de una aplicación tomando una captura de cada uno. También puede emular un dispositivo táctil
para revisar diseños pensados para dedo en lugar de ratón.

El tamaño se emula: **no se redimensiona ninguna ventana tuya**, y por eso puede probarse un
ancho mayor que el de tu pantalla. Cuando tomas el control local, la vista vuelve a su tamaño
real. Cambiar el tamaño no navega, no altera el sitio al que la sesión puede acceder y no
concede ningún permiso nuevo.

## Correcciones incluidas

- **`v1.1.1`** — un análisis de estructura incompleto ya no retira capacidades a un proyecto
  autorizado; la cobertura del análisis pasa a ser información, no un bloqueo.
- **`v1.1.2`** — la detección de campos de credenciales compara palabras completas y deja de
  bloquear campos inocentes como `secretaria` o `wizard`, a la vez que reconoce términos en
  español que antes se le escapaban.

## Compatibilidad

No cambia permisos, proyectos ni configuración existentes. El protocolo MCP sigue siendo
`2026-07-28`. Un cliente que no conozca la nueva capacidad funciona igual que antes.
