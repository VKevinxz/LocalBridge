# LocalBridge MCP `v1.5.0`

`v1.5.0` reúne en **Actividad** los navegadores de desarrollo e Internet y permite tomar
el control humano de una sesión web activa desde LocalBridge. El flujo de desarrollo
existente conserva sus procesos, listeners, HMR, perfiles y permisos.

## Navegación unificada

- **Actividad** muestra recursos `LOCAL` e `INTERNET`, intervenciones pendientes primero y
  filtros para navegadores, procesos y terminales;
- el acceso inicial a Internet se habilita en una sola acción local, con descargas como
  permiso opcional, y los perfiles avanzados siguen disponibles;
- la toma de control puede iniciarse desde la tarjeta activa sin una solicitud MCP previa;
- durante el control humano solo se muestra la pestaña elegida, se pueden recorrer las
  pestañas de la sesión y ChatGPT queda excluido hasta **Devolver a ChatGPT**;
- una sola reserva global impide abrir al mismo tiempo intervalos humanos de Internet y
  localhost.

## Continuidad y sitios con cuenta

ChatGPT descubre primero las sesiones y pestañas vivas para continuar un trabajo. Las
sesiones web se conservan mientras LocalBridge siga abierto cuando la tarea pueda continuar,
y Actividad muestra quién cerró una sesión y cuándo.

Al devolver una navegación pública después de un paso humano, el agente recibe durante un
máximo de 15 minutos acceso al hostname HTTPS exacto que quedó visible. Se destruyen las
demás pestañas y conexiones, se limpian caché y workers y se recarga la URL bajo esa frontera
antes de devolverla; subdominios, redirecciones a otro sitio y conexiones fuera del alcance
fallan cerradas. La persona puede usar esa
concesión una vez, guardar un acceso equivalente sin cookies o continuar en privado.

## Compatibilidad y seguridad

Las pruebas de navegador administradas inician con viewport lógico 1920×1080. ChatGPT puede
solicitar otras resoluciones acotadas; el visor físico se ajusta al monitor y el viewport se
restaura al devolver control. `web.assets` y `web.download` cubren recursos observados con
validación de tipo y firma, URLs visibles sin parámetros firmados y SVG denegado. Los clics
sin efecto inmediato se marcan pendientes y pueden observarse mediante contadores. Las
capturas web y localhost pueden guardarse como PNG; la captura inline usa fallback JPEG si
un PNG no cabe en el broker y `visual.compare` crea un diff acotado con autoridad común.

El catálogo contiene 84 tools y el protocolo MCP permanece en `2026-07-28`. El broker privado
sube a revisión 15 por viewport web, assets y guardado de evidencia. No se importan perfiles,
cookies ni credenciales de Chrome o Edge, y cerrar LocalBridge destruye las sesiones
efímeras. Los paquetes locales quedan integrados en los bundles y fuera del ASAR como
TypeScript fuente, evitando la regresión `ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING`.

El candidato local no se publica automáticamente. El instalador permanece sin firma y las
pruebas físicas de Windows y ChatGPT se documentan por separado.
