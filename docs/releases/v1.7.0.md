# LocalBridge MCP v1.7.0

Fecha de la preview: 11 de septiembre de 2026.

## Qué cambia

- Añade trabajos observables, recuperables y cancelables para operaciones largas. La
  actividad muestra progreso, cobertura, estado del efecto y forma concreta de continuar.
- Añade análisis incremental de archivos grandes: detección de formato, SHA-256, texto
  UTF-8/UTF-16, inspección PE pasiva y procesamiento PDF textual o visual.
- Añade descargas grandes como jobs desde recursos opacos observados por el navegador.
- Permite elegir localmente `Estándar`, un límite personalizado o `Sin límite fijo` para
  artefactos grandes. La última opción procesa por streaming y conserva reservas de disco,
  memoria, respuestas, workers y concurrencia acotadas.
- Reutiliza servidores administrados compatibles entre conversaciones y serializa inicios
  concurrentes para evitar duplicar procesos o puertos.
- Informa la revisión de setup por acción. Una receta guiada pendiente no bloquea la
  terminal ya autorizada en Control total.
- Cambiar una cuota web de consumo conserva las sesiones; cambiar destinos o permisos sí
  invalida la autoridad.
- Las transferencias adaptativas revalidan la autoridad mientras reciben cada bloque y
  vuelven a bloquearla únicamente al publicar. Una revocación limpia el archivo temporal
  sin mantener bloqueada durante horas la edición de cuotas.
- Una descarga cuyo efecto quedó incierto tras un fallo conserva ese estado y no se ofrece
  para reintento automático, incluido un cierre ordenado posterior.
- Corrige pérdida de contraste en determinados PDF escaneados usando PDFium para render
  visual de fuentes de hasta 64 MiB; fuentes mayores conservan PDF.js por rangos y cada
  página informa el motor utilizado. PDF.js sigue extrayendo la capa textual.
- Evita falsos positivos de contenido activo dentro de streams y strings PDF pasivos.
- Añade **Eliminar desarrollo y accesos** con confirmación local: detiene recursos
  exclusivos y retira configuración, permisos, aplicaciones y carpetas autorizadas de
  LocalBridge. Conserva recursos compartidos y los archivos reales en disco.

## Compatibilidad

Las 91 tools anteriores conservan orden y contratos. Las nueve nuevas se agregan al final,
para un total de 100. El registro local migra a schema 5; proyectos existentes quedan en
modo Estándar y los perfiles web 1.6.3 sin política explícita conservan cuotas fijas. El
broker privado usa revisión 19, por lo que Desktop y el servidor incluidos en el instalador
deben actualizarse juntos.

## Seguridad y privacidad

Las entradas MCP nuevas solo aceptan IDs opacos, `workspaceId` y rutas relativas. Ninguna
permite elegir roots, permisos, confianza, límites locales o URL libre. `binary.inspect` no
ejecuta el binario. El journal guarda metadata, progreso, cobertura y recibos; nunca guarda
texto, imágenes ni contenido del archivo. Un efecto incierto después de un crash no se
repite automáticamente.

## Validación del candidato

- DLL PE real de 10.522.624 bytes analizada estáticamente, sin ejecución.
- Fuente sparse de 200 GiB abierta por rangos y texto sparse de 10 GiB paginado.
- PDF virtual mayor de 250 MiB procesado con lecturas acotadas.
- Publicación adaptativa física de 1 GiB + 1 byte completada y eliminada después del test.
- Primera ejecución limpia del paquete: wizard `welcome`, IPC, instancia única y cierre
  mediante `app:quit` verificados sobre `win-unpacked`.
- Validación local previa: 1114 pruebas aprobadas y 3 omitidas; seguridad 327/327;
  TypeScript, lint, cuatro verificadores Electron y servidor empaquetado aprobados.
- Render visual de una página escaneada a 2400×1696 mediante PDFium, sin fallback.

Las pruebas automatizadas verifican contratos y ejecución. La elección de herramientas y
calidad final deben comprobarse también en el flujo real de ChatGPT.
