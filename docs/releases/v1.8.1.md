# LocalBridge MCP v1.8.1

Fecha del candidato: 14 de septiembre de 2026.

## Qué cambia

La pantalla **Actividad** usa divulgación progresiva. Sesiones y recursos, log técnico,
cobertura documental y auditoría se pueden mostrar u ocultar por separado; lotes y grupos
de terminales también se pliegan. Los resúmenes, contadores y acciones generales siguen
visibles. **Contraer todo** no detiene trabajo y una intervención humana permanece fuera de
los paneles, con acceso directo a la sesión afectada.

El botón **Conectar** ahora es el flujo normal para recordar la clave. LocalBridge espera
la señal real de conexión y solo entonces guarda el secreto cifrado con `safeStorage` de
Electron. Al reiniciar, el proceso principal reutiliza la credencial y el campo continúa
vacío. **Recordar en este equipo** permite elegir entre persistencia y una conexión
efímera.

## Recuperación y migración

Los estados de credencial diferencian ausencia, cifrado del sistema no disponible, blob
ilegible y fallo de lectura. Si guardar una clave nueva falla, la conexión permanece activa
y se restaura el blob anterior. Una clave histórica se migra al perfil activo solo cuando
existe un único propietario posible, el destino está ausente y la relectura confirma el
valor; nunca se sobrescribe un destino ni se adivina entre perfiles.

## Privacidad y compatibilidad

El secreto descifrado no cruza hacia el renderer, el DOM, `localStorage`, diagnósticos,
auditoría o exportación portable. DPAPI protege el blob frente a copia directa y traslado a
otra cuenta, aunque no a código que ya se ejecute con la misma cuenta de Windows.

Esta versión mantiene las 113 tools, permisos, jobs, concurrencia, cuotas, límites y
contratos MCP de 1.8.0. Actividad persiste solamente cuatro booleanos de presentación; los
IDs dinámicos viven en memoria y se podan cuando desaparecen los recursos.

## Evidencia

La auditoría interna de cierre relaciona cada requisito con código y pruebas. La guía de prueba
incluye el ciclo de guardar, cerrar, reabrir, conectar sin volver a escribir la clave,
modo efímero, recuperación de errores y una actividad extensa por teclado.
