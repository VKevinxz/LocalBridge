# Código de conducta

## Nuestro compromiso

Queremos una comunidad respetuosa, segura y útil para personas con cualquier nivel de
experiencia. No se toleran acoso, discriminación, amenazas, exposición de datos privados
ni ataques personales.

## Comportamiento esperado

- comunicarse con respeto y centrarse en hechos verificables;
- aceptar correcciones y desacuerdos técnicos de buena fe;
- proteger claves, rutas, contenido y datos personales;
- reportar vulnerabilidades por el canal privado;
- evitar contenido abusivo, sexualizado, intimidatorio o deliberadamente disruptivo.

## Aplicación

Los mantenedores pueden editar o retirar contenido, cerrar interacciones y limitar la
participación cuando sea necesario. Las decisiones se tomarán atendiendo a impacto,
reincidencia y seguridad de la comunidad.

Para reportar una conducta problemática, usa un canal privado del mantenedor indicado en
el perfil del repositorio. No publiques información personal de terceros. Los reportes se
tratarán con la confidencialidad razonablemente posible.

Este código aplica a issues, discusiones, releases y espacios oficiales del proyecto.
